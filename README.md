# AI-Powered Resume Analyzer & Job Matcher (Enhanced)

Light futuristic Streamlit demo + backend modules.

Features:
- Multimodal resume ingestion (PDF/DOCX/Image OCR)
- Semantic matching with Sentence-Transformers
- LLM Re-Ranker & Explanation (OpenAI / Bedrock placeholders)
- Automated Resume Rewriter (impact-first bullets via LLM)
- Recruiter Snapshot PR Pack generator (1-page PDF)
- Hireability Score heuristic + trainable model placeholder
- GitHub Portfolio Evidence quick analysis
- Mobile-first resume photo capture instructions

## Quickstart
1. Install Tesseract OCR (system).
2. Create venv and install: `pip install -r requirements.txt`
3. Run: `streamlit run app.py`
